# Master plan

A good base is a logistics problem first and a building project second. Get safe, get food, get a bed, then pick a site you will still want in a month.

Game version: Wilderness Bound (Java 26.3 / Bedrock 26.50), so straw beds, abandoned camps, and copper gear all matter in the first week.

## Phases

| # | Phase | When | Goal | Done when |
| --- | --- | --- | --- | --- |
| 1 | [First night](phase-1-first-night.md) | Night 1 | Do not die | Bed, a stack of food, a stone tool set, and a chest |
| 2 | [Starter outpost](phase-2-starter-outpost.md) | Days 1–3 | A shack near spawn, not a home | Iron tools and armor, a self-refilling food farm, a sorted chest |
| 3 | [Pick the real site](phase-3-pick-the-site.md) | Before you build walls | Find a site you'll still want in a month | Site marked, and the bed moves once it has a door, light, and a chest |
| 4 | [The base that lasts](phase-4-the-base.md) | Week 1–2 | Function rooms before looks | Storage, workshop, food wing, mine entrance, perimeter, spawn control |
| 5 | [Infrastructure](phase-5-infrastructure.md) | Once iron is boring | Each addition removes a chore | Trading hall, farms, boxed portal, roads, backups |

## Big goals

- [Storage and sorting](storage-and-sorting.md): a highly automated item sorter with heavy use of copper golems. Starts with the Phase 4 storage wall, grows into the Phase 5 storage system.

## Supporting plans

## First-session checklist

- [ ] Bed set
- [ ] Food farm planted
- [ ] Iron tools
- [ ] Site chosen
- [ ] Storage started

Everything else is optional until those five are done.
