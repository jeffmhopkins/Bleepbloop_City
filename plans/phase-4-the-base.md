# Phase 4 — The base that lasts

**When:** Week 1–2
**Goal:** Build function rooms before looks.
**Status:** ⬜ Not started

## Tasks

### 1. Storage wall
- [ ] Double chests in a row
- [ ] Label them: wood, stone, ores, food, mob drops, redstone, junk
- [ ] One input chest by the door so you can dump inventory fast

> **Display option:** shelves (Copper Age) show 3 stacks each, which suits a sample or display wall in the storage hall. On Bedrock a powered shelf only reacts on certain redstone ticks, so test any shelf redstone first.

> **Big goal:** this storage wall is the start of the [automated item sorter](storage-and-sorting.md). Hopper sorting is the main system; copper golems are a showpiece gallery. How to group things: [storage-layout.md](storage-layout.md). Barrels make a good input by the door (hoppers empty them).

### 2. Workshop
- [ ] Crafting table
- [ ] Furnaces
- [ ] Anvil
- [ ] Grindstone
- [ ] Cartography table
- [ ] Loom
- [ ] Later: smithing table
- [ ] Later: enchanting setup (15 bookshelves)
- [ ] Later: **shelves** (6 stripped logs make 6). Each holds 3 stacks on display. A **powered** shelf swaps its items with the right side of your hotbar, so a row of them makes a quick-swap kit station (mining kit, building kit). Placement is Jeffrey's call.

### 3. Food wing
- [ ] Crop farm
- [ ] Composter
- [ ] Smoker
- [ ] Small animal barn with a gate
- [ ] A cauldron or water source for bottles

### 4. Mine entrance
- [ ] A lit staircase or a water elevator down to the branch mine
- [ ] Branch at Y=-54 or around diamond level, once you have iron picks to spare
- [ ] Keep a safe path back up

### 5. Perimeter
- [ ] Fence or wall
- [ ] Torches on the outside
- [ ] A gate
- [ ] Light the ground inside the walls (mobs spawn on unlit ground inside the walls)

### 6. Spawn control
- [ ] Light or slab every dark spot in the build
- [ ] Use floors of slabs, stairs, or bottom-half blocks to stop spawns

### 7. Local-area map
Coordinates are off, so a map is the main way to see the area. Paper comes from sugar cane (3 cane → 3 paper), the compass from 4 iron + 1 redstone, and item frames from 8 sticks + 1 leather. Steps and verified Bedrock details are in the [session plan's map thread](../progress/session-plan.md#map-thread-a-local-area-map).
- [ ] Sugar cane planted by water (it gates paper for both maps and books)
- [ ] Cartography table (2 paper + 4 planks; it's also in §2). With it, a map costs 1 paper and a locator map costs 1 paper + a compass.
- [ ] First locator map of the base and spawn (zoom level 0, 128×128 blocks), filled by walking around while holding it
- [ ] Zoomed-out local-area map (level 2 = 512×512 or level 3 = 1024×1024) showing the mountain, cherry grove, cave entrance, ocean, ice and village. Zoom it **before** filling, because zooming wipes the drawing.
- [ ] Wall map in item frames near the base door or storage entrance (placement and look are Jeffrey's call), plus a clone to carry
- [ ] Landmarks the maps show are logged in [coordinates](../notes/coordinates.md)
