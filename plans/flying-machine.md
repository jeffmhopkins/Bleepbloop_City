# Flying machine

**When:** End game (after the core farms and storage are running)
**Goal:** Build a working flying machine.
**Status:** ⬜ Not started

## What it is

A flying machine is a redstone contraption that moves itself across the world, built from slime blocks, sticky pistons, and observers.

> **Note:** pistons behave differently on Java and Bedrock, so a design that works on one edition may not work on the other. The server is **Bedrock**, so use a Bedrock flying machine design.
